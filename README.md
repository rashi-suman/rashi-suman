Production-grade B2B outreach platform designed to scale to **10M+ contacts** and **1M+ emails/day**.

**Key Engineering Highlights:**

- ⚡ **Queue-based Asynchronous Architecture:** Built BullMQ workers, schedulers, and webhook processing to eliminate blocking workloads and reduce failed campaign jobs by **40%**.
- 🤖 **AI Enrichment Pipeline:** Designed a 3-pass Claude AI enrichment workflow (Company → Person → Cross-verify) with confidence scoring and source attribution.
- 🔐 **Secure Architecture:** Implemented role-based access control (RBAC) and secure session management.
- 📊 **Large-scale Data Processing:** Built CSV/XLSX imports with keyset pagination optimized for millions of rows.

**Tech:** `Node.js` · `Express.js` · `MySQL` · `Redis` · `BullMQ` · `Anthropic Claude API`
